# Sistema de Gestion - HLConsulting

Este proyecto es una aplicación de gestión basada en el flujo de datos de una consultora que tramita habilitaciones de empresas de seguridad y personal de las mismas.

## Tecnologías Principales
- Python (backend / API).
- Power Platform (frontend, integración, automatización).
- DAX & Power BI (análisis de datos y reportes).
